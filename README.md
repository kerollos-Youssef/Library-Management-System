# 📚 Library Management System (C++)

A lightweight, console-based Library Management System built in C++ utilizing Object-Oriented Programming (OOP) concepts and C++ Standard Template Library (STL). This application allows managing books and users, tracking book borrowing and returning processes, searching titles, and generating library status reports.

---

## ✨ Features

* **📖 Book Management:**
  * Add new books with ID, Title, Author, and Available Copies count.
  * Search books by title and view available quantity.
* **👤 User Management:**
  * Register new library users with User ID and Name.
  * View list of books currently borrowed by a specific user.
* **🔄 Borrowing & Returning:**
  * Borrow books with automated stock check and deduction.
  * Return borrowed books and update available stock dynamically.
* **📊 Comprehensive Reports:**
  * Print full reports listing all registered users and available books in stock.
* **💻 Interactive CLI Menu:**
  * Simple, user-friendly command-line interface with error handling for non-existing users/books.

---

## 🛠️ Concepts & Technologies Used

* **Language:** C++ (C++11 or higher)
* **Object-Oriented Programming (OOP):**
  * Class Encapsulation (`Book`, `User`, `LibrarySystem`)
  * Constructors & Destructors
  * Pointers & References
* **Standard Template Library (STL):**
  * `std::vector` for dynamic storage of users and books.
  * Range-based `for` loops & Iterators for efficient traversal.
